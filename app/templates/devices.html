Add a device
  1. On the phone, turn on Settings → Developer options → Wireless debugging. The phone and this server must be on the same network.
  2. Note the IP address & port shown on the Wireless debugging screen. That's the connect address.
  3. Tap Pair device with pairing code. Enter the address and 6-digit code it shows, plus the connect address, below.
  4. Once it's paired, press Trust on its card. Nothing is ever pushed to an untrusted device.

The connect port changes whenever wireless debugging restarts. Pushes find the new port automatically by scanning the device's last known IP; Find does the same on demand.

Connection

What Find does: the phone picks a new port every time wireless debugging restarts, so the saved address stops working. Find tries the saved address first. If nothing answers, it scans that same IP for the new port and reconnects. It only accepts a port if the phone there reports this device's serial, so it never latches onto a different phone. Pushes and installs do this on their own when the saved port has gone stale. Use Find to check a phone is reachable before you install, or after you turn wireless debugging back on. It can take a few seconds. If the phone's IP address changed, use Reconnect with the new address instead.
