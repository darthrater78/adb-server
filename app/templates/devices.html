What Find and Reconnect do

The phone picks a new port every time wireless debugging restarts, so the saved address stops working. Find tries the saved address first. If nothing answers, it scans that same IP for the new port and reconnects. It only accepts a port if the phone there reports this device's serial, so it never latches onto a different phone. Pushes and installs do this on their own when the saved port has gone stale. It can take a few seconds. If the phone's IP address changed, use Reconnect with the new address instead.
